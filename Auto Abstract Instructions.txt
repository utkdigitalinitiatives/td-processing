Abstract detection, OCR, and HTML markup
Modules: numpy 2.4.4; paddleocr 3.4.0; paddlepaddle 3.0.0 (only compatible with python3.11 run as py -3.11 your_script.py); pillow 12.1.1

Run in virtual environment. If venv folder does not exist, open powershell window in blank space and type: py -3.13 -m venv .venv 
If venv FOLDER EXISTS .\.venv\Scripts\activate

Add PDFs to inputs folder

Run: py .\abstract_ocr_paddle_cuda.py --input inputs --out outputs

This will add HTML or TXT files to outputs folder. 

Not detecting new paragraphs or removing line breaks


Optionally add `--override-csv override.csv` to specify which pages to extract
